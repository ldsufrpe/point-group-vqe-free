# figures/

Manuscript-bound figures are PDF, sized for the single-column or full-width block of the
REVTeX family that Quantum follows, and drawn from the Okabe-Ito palette with black reserved
for reference curves. The PNG next to each PDF is a raster preview for inspection and is not
for the manuscript.

`figure_manifest.json` lists every element each figure actually draws, keyed by the figure
descriptor. It is structured fact for the drafting and review stages, not caption prose.
Regenerate everything here with `python code/analysis.py`.
